💰 Calculadora de Gastos

Projeto desenvolvido durante o curso Técnico em Desenvolvimento de Sistemas com o objetivo de praticar programação utilizando TypeScript e desenvolvimento de aplicações web.

🧮 Sobre o projeto

O projeto consiste no desenvolvimento de uma calculadora de gastos, criada para praticar conceitos de programação utilizando TypeScript.

A aplicação possui um site local host desenvolvido com HTML e CSS e utiliza TypeScript para a implementação da lógica da aplicação.

🛠️ Tecnologias utilizadas
🌐 HTML
🎨 CSS
🔷 TypeScript
🟢 Node.js
📦 npm
📚 Conceitos praticados
Estruturação de páginas com HTML
Estilização com CSS
Programação com TypeScript
Tipagem estática
Organização de arquivos em projetos TypeScript
Compilação de TypeScript para JavaScript
Configuração de projeto com tsconfig.json
Gerenciamento de dependências com npm

Praticar os fundamentos de TypeScript e desenvolvimento web, utilizando uma aplicação simples para exercitar a criação e organização de um projeto.
